# Its Podomoro - Minimalist Aesthetic Focus Suite

**Its Podomoro** is an ultra-clean, minimalist Pomodoro timer application featuring 9 dynamic organic motion background scenes, sound ambience, tab icons, and a timestamp-accurate timer engine.

![Its Podomoro](https://raw.githubusercontent.com/thanzeroo/podomoro/main/preview.png)

## ✨ Features

- **9 Organic Dynamic Canvas Motion Themes**:
  1. *Cyber Neon*
  2. *Deep Space*
  3. *Cozy Rain*
  4. *Forest Breeze*
  5. *Retro Horizon*
  6. *Fluid Aurora*
  7. *Matrix Digital Rain* (New)
  8. *Midnight Fireflies* (New)
  9. *Sunset Ocean Waves* (New)
- **Timestamp-based Countdown Engine**: Prevents unexpected timer resets and maintains exact millisecond precision.
- **Tab Icon & Custom Branding**: Updated branding to "Its Podomoro" with SVG favicon icon.
- **Clean Zen Focus Mode**: Toggle interface visibility for zero-distraction focus sessions.
