# Podomoro Time - Ultra Minimalist Cyber Focus Suite

Podomoro Time is a modern, ultra-minimalist Pomodoro focus timer application built with HTML5, CSS3, and JavaScript. It features an interactive **Generative Motion Canvas Background Engine** with 6 dynamic customizable themes, clean Zen mode, audio ambience generator, task management, and productivity analytics.

![Podomoro Time](https://raw.githubusercontent.com/thanzero0/podomoro/main/preview.png)

## ✨ Features

- **6 Generative Motion Background Scenes**:
  1. *Cyberpunk City Rain* - Neon urban rain animation.
  2. *Cosmic Nebula Galaxy* - Twinkling stars and rotating nebula particles.
  3. *Cozy Lofi Rain Drops* - Warm ambient rain condensation.
  4. *Serene Bamboo Forest* - Swaying emerald leaves in serene breeze.
  5. *Sunset Synthwave Grid* - 80s retro-futuristic perspective grid and sunset.
  6. *Organic Liquid Flow* - Morphing dynamic fluid color gradients.
- **Single Master Control Panel (`Controls`)**: All audio, theme, timer, and analytics configurations organized in a unified drawer.
- **Zen Clean Mode**: Hide interface button to switch to 100% distraction-free fullscreen timer display.
- **Task Management**: Integrated task tracker with Pomodoro estimation and active task targeting.
- **Audio Ambience Synthesizer**: Built-in sound machine for Rain, Waves, Forest, Space, Fire, and Ticking clock sounds.
- **Productivity Dashboard**: Daily streak counter, weekly focus chart, and session completion metrics.

## 🚀 Getting Started

Simply clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/thanzero0/podomoro.git
cd podomoro
# Open index.html in your browser or run a local HTTP server
python3 -m http.server 8080
```
